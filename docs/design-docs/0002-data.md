# ADR 0002 — Data: a committed snapshot, ingested from swapi.info

Status: **accepted** (2026-10-05). Implementation: `swr-3mo.4`.

## Context

`api.starwars.run` no longer answers. The owner wants a much larger dataset over time
(Wookieepedia and others) and chose swapi.info as the starting point.

swapi.info, as observed on 2026-10-05:

- Base URL `https://swapi.info/api/`, with six resources: `films`, `people`, `planets`,
  `species`, `vehicles`, `starships`.
- Each resource URL returns the **whole collection as one JSON array**: 6 films, 82 people,
  60 planets, 37 species, 39 vehicles, 36 starships. 260 records in total.
- `?search=` is **ignored**; it returns the full list.
- Cross-origin requests are allowed (`access-control-allow-origin: *`). The site claims no
  rate limit.
- Records link to each other by URL (`"homeworld": "https://swapi.info/api/planets/1"`).
  Missing values arrive as the strings `"unknown"` and `"n/a"`, and numbers as strings,
  sometimes with commas.
- No images.

## Decision

- `pnpm ingest` fetches all six resources, parses them into domain records, and writes a
  snapshot to `data/`. The snapshot is **committed**. `pnpm build` reads only the snapshot
  and never the network.
- Parsing happens once, at the boundary (`src/ingest/`). Unknown values become absent, not
  the string `"unknown"`. Numbers become numbers. A shape the parser doesn't expect fails
  the ingest.
- Each record gets a readable slug, unique within its type: `/people/luke-skywalker/`,
  `/planets/tatooine/`. URLs are built from slugs, never from swapi IDs, so they stay stable
  if the source changes.
- Source URLs become links by slug. **A link to a record that doesn't exist fails the
  ingest.** Links are shown in both directions: a planet lists its residents, and a person
  links to their homeworld.
- The record shape notes which source each fact came from, so a second source can merge in
  later without a rewrite.
- Search runs on the built site, not against the source.

## Consequences

- Builds are reproducible, and the snapshot diff shows what changed upstream.
- Data goes stale until someone runs `pnpm ingest` again. That's fine for a saga that
  changes slowly.
- **Later:** Wookieepedia (`swr-4g6`, a spike) has hundreds of thousands of articles,
  licensed CC BY-SA. At that scale, a committed JSON snapshot and one HTML page per article
  may stop being practical. The spike decides that. Images (`swr-8to`) wait on it.
